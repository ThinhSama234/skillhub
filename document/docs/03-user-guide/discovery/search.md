# Search Skills

## Full-Text Search

Enter keywords in the search box. SkillHub searches across the following fields:
- Skill name
- Skill description
- Skill slug
- Other frontmatter fields besides `name`, `description`, and `version`
- Keyword fields such as `keywords` / `tags`

## Filter Options

You can filter search results using the following criteria:
- Namespace
- Visibility
- Sort by downloads
- Sort by rating
- Sort by last updated

## Advanced Search

Use search syntax:
- `namespace:@team-ai` - filter by namespace
- `category:code-review` - filter by category
- `downloads:>100` - more than 100 downloads
